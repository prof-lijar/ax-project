# Generated Calculator

`calculator.py` is a deterministic calculator generated by the Scheduling
Agent POC.

## Supported operations

- `add(left, right)`
- `subtract(left, right)`
- `multiply(left, right)`
- `divide(left, right)`

## Basic usage

```python
from calculator import add, divide

print(add(2, 3))
print(divide(10, 2))
```

`divide()` raises `ValueError` when the divisor is zero.

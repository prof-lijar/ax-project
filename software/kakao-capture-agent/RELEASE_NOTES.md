Download `KakaoCaptureAgent-v<VERSION>-windows-x64.exe` from Assets and double-click it on Windows 10/11 (64-bit). Python, uv, and a separate installation step are not required. First launch may take a moment while bundled libraries unpack.

Open your authorized KakaoTalk conversation, select its window and message region, and enter a chat identifier in Settings. Configure your upload API and token if needed; a blank URL keeps captures local. Keep the chat visible and Windows unlocked. Ctrl+Shift+F12 stops automated capture/navigation.

This is a prerelease. The Windows build runs automated tests and a synthetic packaged-app startup check. Real KakaoTalk capture/scroll calibration, mixed-DPI desktop behavior, and the 24-hour unattended acceptance test still require validation on the target PC. Screenshots do not guarantee complete message coverage.

The executable is unsigned, so Windows may display an unrecognized-app prompt. A SHA-256 checksum is included. Downloads from this private repository require repository access. See the README and TESTING.md in the tagged source for setup and validation details.

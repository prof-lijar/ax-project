# AX Project Requirement Analysis

This folder contains first-pass requirement analysis notes for Nextor.ai's AX Project.

AX Project is focused on transforming existing projects, products, services, and microservice extensions with AI and AI agents. The analysis is based on the provided project notes, design specs, diagrams, hardware context, and the `안심지키미` smart care service example.

## Files

- [01_project_context.md](01_project_context.md): project scope, known facts, assumptions, and information gaps.
- [02_use_case_shortlist.md](02_use_case_shortlist.md): suggested AX use cases and pilot candidates.
- [03_requirements.md](03_requirements.md): functional and non-functional requirements.
- [04_architecture_requirements.md](04_architecture_requirements.md): suggested architecture layers and component requirements.
- [05_implementation_phases.md](05_implementation_phases.md): phased delivery plan from discovery to pilot.
- [06_risks_and_questions.md](06_risks_and_questions.md): risks, constraints, and questions to resolve early.
